# YouTube Music History Analyzer

## [https://pokobi.github.io/YouTube-Music-History-Analyzer/](https://pokobi.github.io/YouTube-Music-History-Analyzer/)

Google Takeout で書き出した YouTube Music の再生履歴（watch-history.json）をブラウザ上で集計し、ランキングやグラフを表示するツール。

## 機能

* 読み込み
    * watch-history.json、Takeout の ZIP（解凍不要）、このツールのバックアップ JSON に対応。
    * 複数ファイルの同時読み込みと、後からの追加読み込みに対応。保存済みのデータに結合され、同じ日時・同じ曲の記録は重複として除外される。
    * 読み込んだデータはブラウザ（IndexedDB）に保存され、次回アクセス時に自動で復元される。
    * 旧バージョンで保存したデータは自動で引き継がれる。
* 集計期間
    * 全期間、直近 30 日・90 日・1 年、年ごと、任意の期間から選択。
    * 選択中の画面と期間は URL に保持される。
* 概要
    * 再生回数、推定再生時間、再生した日数、1 日あたりの再生回数、最長連続日数、曲数、アーティスト数、スキップ数。
    * 前の期間（年を選んだ場合は前年）との比較。
    * 再生回数の推移（月別、短い期間では日別）と、日ごとの再生回数のカレンダー。カレンダーの日を選ぶと、その日に再生した曲の一覧を表示。
* ランキング
    * 曲・アーティストの全件ランキング。回数順と推定再生時間順を切り替え可能。同数は同順位。
    * 前の期間からの順位の変動。
    * 曲名・アーティスト名での検索（順位は元のまま表示）。
* 傾向
    * 時間帯別、曜日別、曜日 × 時間帯の再生回数。
    * ハマった曲（30 日間に集中して再生した曲）と、最近聴いていない曲。
    * アーティスト別の再生割合、年ごとの再生回数。
    * 月ごとの初めて聴いたアーティスト・曲の数。
* 比較
    * 2 つの期間の数値と、上位の曲・アーティストの順位を並べて比較。
* 年間まとめ
    * 年ごとの再生回数、いちばん聴いた曲・アーティスト、よく聴いた月・曜日・時間帯、TOP 10、その年に初めて聴いたアーティスト。
* 詳細画面
    * 曲・アーティストごとの再生回数、順位、推定再生時間、ハマった時期、初再生日、月別の推移、再生した日時の一覧。
    * アーティストのよく聴いた曲。
* 推定再生時間とスキップ
    * 次の再生までの間隔から、聴いた時間を推定する（その曲のふだんの長さが上限）。
    * 次の再生まで 30 秒未満の再生をスキップとみなす。スキップを集計から除外する設定あり。
* 集計の調整
    * 曲・アーティストを集計から除外。
    * 表記違いなどで分かれた同じアーティストを 1 つにまとめる。「- Topic」の付いたチャンネルは自動でまとめる。
    * MV 版と音源版など、別々に記録された同じ曲を 1 つにまとめる。曲名が付記違いの曲はまとめ候補として表示する。
* 曲の原題とアーティスト画像（外部サービスから取得。設定でオフにできる）
    * 英語やローマ字で書き出された曲名を、YouTube に登録されている原題に置き換える。書き出されたときの表記は「別の表記」として残り、検索にも使える。
    * YouTube でも英語やローマ字で登録されている曲名・アーティスト名は、iTunes Search API（日本のストア）で日本語の表記を探す。iTunes のアーティストの曲の一覧と照らしてアーティストを確かめ、日本語の曲名が多いアーティストの場合だけ採用する。曲名は、別の版（ライブ・リミックスなど）かどうかが一致する場合だけ採用する。
    * アーティスト画像は、Spotify に設定されている画像を優先して使う。照合済みの Apple・Deezer のアーティスト ID から Wikidata で Spotify のアーティスト ID を調べるため、同じ名前の別のアーティストにはならない。
    * Spotify の画像がないときは Deezer API の写真を使う。同じ名前の別のアーティストを避けるため、よく聴いた曲を検索して本人の曲が見つかった場合だけ使う。確かめられないときは、いちばん聴いた曲のジャケットを表示する。
    * YouTube Data API のキーを設定すると、曲名をまとめて取得し、チャンネルのアイコンを優先して表示する。キーはブラウザにだけ保存され、バックアップには含まれない。
* 書き出し
    * バックアップ（JSON）。再生記録と除外・まとめの設定を含む。
    * 曲・アーティストのランキング（CSV）。
* 保存データの保護（ブラウザが容量不足で自動削除しないようにする設定）に対応。
* ライト・ダークテーマ、スマートフォン表示に対応。

## 使い方

### 再生履歴の書き出し

1. [Google Takeout](https://takeout.google.com/) を開き、「選択をすべて解除」を押す。
2. 「YouTube と YouTube Music」にチェックを入れる。
3. 「YouTube のすべてのデータが含まれます」を押し、「履歴」のみを選択して OK を押す。
4. 「複数の形式」を押し、履歴の形式を「JSON」にする。
5. 「次のステップ」→「エクスポートを作成」を押す。
6. 届いた ZIP をそのまま、または中の `Takeout/YouTube と YouTube Music/履歴/watch-history.json` を読み込む。

### 読み込み

画面中央の枠にファイルをドロップするか、枠をクリックしてファイルを選択する。データ読み込み後は、ページのどこにドロップしても追加で読み込める。

## 注意事項

* 再生履歴はブラウザの中だけで処理・保存され、外部には送信されない。
* 曲のジャケットやアーティストの画像は YouTube の画像サーバーから読み込む。データ管理画面でオフにできる。
* 曲の原題とアーティスト画像の取得では、次の情報を外部サービスへ送信する。データ管理画面でオフにすると送信しない。
    * YouTube（youtube.com、API キー設定時は googleapis.com）: 動画 ID、チャンネル ID
    * Apple（itunes.apple.com）: 曲名、アーティスト名
    * Deezer（api.deezer.com）: アーティスト名、曲名
    * Wikidata（query.wikidata.org）: Apple・Deezer のアーティスト ID
    * Spotify（open.spotify.com）: Spotify のアーティスト ID
* iTunes Search API には回数制限があるため、日本語の表記の取得は少しずつ行い、続きは次に開いたときに行う。
* watch-history.json には再生を始めた日時だけが記録されており、聴いた長さは記録されていない。再生時間とスキップは次の再生までの間隔からの推定で、実際とは異なる場合がある。
* 曲名・アーティスト名は、原題の取得をオフにしている場合、YouTube が書き出したとおりに表示する。
* 保存したデータは、別のブラウザやシークレットウィンドウとは共有されない。

## 動作環境

* Google Chrome、Microsoft Edge、Firefox、Safari の最新版。

## 開発

* ビルド不要。リポジトリのルートを静的サーバーで配信すると動作する（ES Modules を使うため、`file://` では開けない）。
* テスト: `npm test`（Node.js 22 以降）。push 時に GitHub Actions でも実行される。
* ZIP の展開に [fflate](https://github.com/101arrowz/fflate)（MIT License）を同梱している。

ほとんどのコーディングは生成AIです。
