# **YouTube Music History Analyzer**

YouTube Musicの再生履歴データ (watch-history.json) を読み込み、あなたの音楽の趣向を詳細に分析・可視化するツールです。

## **特徴**

* **完全ローカル処理**: アップロードされたデータはブラウザ内でのみ処理され、外部サーバーには一切送信されません。安心してご利用いただけます。  
* **履歴の自動保存**: 一度読み込んだデータはブラウザに保存され、次回からはワンクリックで解析を開始できます。  
* **多彩な分析機能**:  
  * **総合統計**: 総再生回数、アクティブ日数、最長連続再生記録など。  
  * **ランキング**: 楽曲・アーティストごとの再生数ランキング（TOP100）。  
  * **期間絞り込み**: 年ごと、またはカレンダーによる自由な期間指定が可能。  
  * **グラフ表示**: 時間帯別、月別、アーティストシェア（円グラフ）などの可視化。  
  * **詳細分析**: 各楽曲・アーティストをクリックすると、詳細な再生履歴（日時リスト）や推移グラフを確認できます。

## **使い方**

### **1\. データの取得 (Google Takeout)**

まず、Googleからご自身のYouTube再生履歴データをダウンロードする必要があります。

1. [Google Takeout](https://takeout.google.com/) にアクセスします。  
2. **「選択をすべて解除」** をクリックします。  
3. リストを下にスクロールし、**「YouTube と YouTube Music」** のみにチェックを入れます。  
4. 「YouTube のすべてのデータが含まれます」ボタンをクリックし、**「履歴」のみを選択**して「OK」を押します（動画などの他のデータは不要です）。  
5. 「複数のフォーマット」ボタンをクリックし、履歴が\*\*「JSON」\*\*形式になっていることを確認します。  
6. ページ最下部の\*\*「次のステップ」\*\*をクリックします。  
7. 「頻度」は「1回エクスポート」、「ファイル形式」は「.zip」を選択し、\*\*「エクスポートを作成」\*\*をクリックします。  
8. 準備ができるとGoogleからメールが届きます（データ量により数分〜数時間かかります）。ダウンロードしてZIPファイルを解凍してください。  
9. 解凍したフォルダ内の Takeout/YouTube と YouTube Music/履歴/watch-history.json (または 再生履歴.json) が必要なファイルです。

### **2\. データの読み込み**

1. Music History Analyzer をブラウザで開きます。  
2. 中央のドロップエリアに、先ほど取得した watch-history.json をドラッグ＆ドロップ（またはファイル選択）します。  
3. 解析が完了すると、自動的にダッシュボードが表示されます。

### **3\. ダッシュボードの機能**

* **フィルタリング**: 右上のプルダウンやカレンダーアイコンから、集計期間を変更できます。  
* **検索**: 曲名やアーティスト名でランキングを絞り込めます。ヒット件数がバッジで表示されます。  
* **詳細確認**: ランキング内の曲名やアーティスト名をクリックすると、詳細な再生履歴と月別推移グラフが表示されます。  
* **コピー**: 名前の横にあるコピーアイコンをクリックすると、クリップボードにコピーできます。  
* **保存**:  
  * CSV保存: 現在のランキングデータをExcelなどで開けるCSV形式でダウンロードします。  
  * JSONバックアップ: 解析データを軽量なJSONファイルとしてバックアップ保存します。

## **注意事項**

* **表記について**: YouTube Musicのデータ仕様上、アーティスト名や楽曲名の一部が英語（ローマ字）表記になってしまう場合があります（例: 「幾田りら」→「Lilas Ikuta」）。これはデータソース側の仕様によるものです。  
* **再生時間の分析について**: watch-history.json には「いつ再生したか」という記録はありますが、「何分間再生したか」という情報は含まれていません。そのため、本ツールでは再生回数ベースの分析のみを提供しており、再生時間の集計はできません。

## **動作環境**

最新のモダンブラウザ（Chrome, Edge, Firefox, Safariなど）で動作します。  
JavaScriptが有効になっている必要があります。
