# YouTube Music History Analyzer

YouTube Musicの再生履歴データ(watch-history.json)から、自分自身の再生記録や視聴傾向を分析して画面に表示するためのツールです。

## 機能について

アップロードされたデータはすべてお使いのブラウザの中だけで処理される仕組みになっています。外部のサーバーにデータが送信されることはないので、プライバシーの面では安全に利用できます。
また、一度読み込んだデータはブラウザ内に自動で保存されるように作りました。そのため、次回以降にアクセスした際は毎回ファイルを選択しなくても、過去に読み込んだデータをワンクリックで再び画面に表示させることができます。

分析できる内容としては、まず総再生回数やアクティブだった日数、最長連続再生記録などの全体的な統計情報があります。それに加えて、よく聴く楽曲やアーティストのランキングをトップ100まで表示します。
期間の絞り込みにも対応しており、特定の年だけを見たり、カレンダーを使って任意の日付の範囲を指定して集計し直すことも可能です。
グラフ表示の機能も用意しました。時間帯別の再生傾向や月別の推移、アーティストごとの再生割合を円グラフなどで視覚的に確認できます。
さらに、ランキングに表示されている個別の曲やアーティストの項目をクリックすると、その曲やアーティストに絞った詳細な再生履歴の日時リストや、月別の再生推移のグラフを個別に確認できる機能もあります。

また、複数の履歴ファイルを結合するマージ機能も備えています。期間の異なる複数のwatch-history.jsonを同時に選択して読み込ませたり、すでにデータを読み込んでいる状態からさらに追加で別のファイルを読み込ませることが可能です。その際、再生日時などの情報からデータが重複している部分を自動で判別して除外するため、同じ曲の再生が二重にカウントされることはありません。

## 使い方

### データの取得
このツールを使うには、事前にGoogleのサービスから自分のYouTubeの履歴データをダウンロードしておく必要があります。

1. [Google Takeout](https://takeout.google.com/) にアクセスします。  
2. **「選択をすべて解除」** をクリックします。  
3. リストを下にスクロールし、**「YouTube と YouTube Music」** のみにチェックを入れます。  
4. 「YouTube のすべてのデータが含まれます」ボタンをクリックし、**「履歴」のみを選択**して「OK」を押します（動画などの他のデータは不要です）。  
5. 「複数のフォーマット」ボタンをクリックし、履歴が\*\*「JSON」\*\*形式になっていることを確認します。  
6. ページ最下部の\*\*「次のステップ」\*\*をクリックします。  
7. 「頻度」は「1回エクスポート」、「ファイル形式」は「.zip」を選択し、\*\*「エクスポートを作成」\*\*をクリックします。  
8. 準備ができるとGoogleからメールが届きます（データ量により数分〜数時間かかります）。ダウンロードしてZIPファイルを解凍してください。  
9. 解凍したフォルダ内の Takeout/YouTube と YouTube Music/履歴/watch-history.json (または 再生履歴.json) が必要なファイルです。

### 読み込みと操作
ツールをブラウザで開いたら、画面の中央にある枠の中に先ほどのwatch-history.jsonファイルをドラッグ＆ドロップしてください。ファイルを選択するボタンから選ぶことも可能です。複数のファイルを一度に選択して読み込ませることもできます。読み込みと解析が終わると自動的に統計画面に切り替わります。

画面の右上にあるプルダウンメニューやカレンダーのアイコンから、集計したい期間を変更できます。
検索枠に曲名やアーティスト名を入力すると、ランキングの表示を絞り込むことができます。ヒットした件数も表示されます。
項目の横にあるコピーボタンを押せば名前をクリップボードにコピーできますし、右上のボタンから現在表示されているランキングのデータをCSV形式でダウンロードして表計算ソフト等で開いたり、解析済みのデータを軽量なJSONファイルとしてバックアップとして保存することも可能です。

## 注意事項

YouTube Musicのシステムから出力されるデータの仕様により、一部のアーティスト名や楽曲名がアルファベットのローマ字表記になってしまうことがあります。これは出力される元のデータ自体がそうなっているので、現在の仕様となります。
また、watch-history.jsonというファイルには、その曲を「いつ再生し始めたか」という時間は記録されているのですが、「何分間聴いていたか」という時間は記録されていません。そのため、このツールでは再生時間に基づく分析はできず、あくまで再生した回数に基づいた集計結果のみを表示しています。

## 動作環境

Chrome、Edge、Firefox、Safariなどのブラウザの最新版で動作します。
JavaScriptが有効になっている必要があります。パソコンのブラウザでの利用を想定しているため、スマートフォンなどの画面が小さい端末での表示は最適化されていません。
