# YouTube Music History Analyzer

YouTube Musicの再生履歴データ（watch-history.json）をブラウザ上で解析し、再生傾向や統計情報を表示するためのツールです。

## 機能について

本ツールは以下の機能を備えています。

* 完全ローカル処理: アップロードされた履歴データはブラウザ内でのみ処理されます。外部サーバーへの送信は一切行われないため、プライバシーは保護されます。
* データの自動保存: 一度読み込ませたデータはブラウザ（IndexedDB）に自動的に保存されます。次回アクセス時はファイルを選択しなくても前回までのデータが即座に復元されます。
* 全体統計の算出: 総再生回数、アクティブ日数、1日あたりの平均再生回数、最長連続再生記録（日数）、ユニークな楽曲数やアーティスト数を算出します。
* ランキング表示: 楽曲およびアーティストの再生回数ランキングをトップ100まで一覧表示します。検索ボックスからの絞り込みにも対応しています。
* 期間指定フィルタリング: 特定の年ごとの集計や、カレンダーを用いた任意の日付範囲（例：2023年4月1日〜2023年10月31日）での絞り込み表示が可能です。
* グラフ表示機能: アーティストの再生割合（円グラフ）、時間帯別の再生傾向（棒グラフ）、月別の再生推移（棒グラフ）を視覚化します。
* 詳細履歴の確認: ランキングの各項目をクリックすることで、その楽曲やアーティスト単体の月別再生推移や、過去の全ての日時単位の再生履歴リストを確認できる画面を表示します。
* 複数データの結合（マージ）機能: 期間の異なる複数の履歴ファイルを同時に選択したり、後から追加で読み込ませてデータを統合することが可能です。再生日時や楽曲情報に基づき、重複しているデータは自動で除外されます。また、再アクセス時に新しいファイルを追加した場合も、内部に保存された過去のデータと自動的に結合されます。

## 使い方

### 履歴データの取得

解析対象となるデータは、Googleの公式サービスからご自身でダウンロードする必要があります。

1. [Google Takeout](https://takeout.google.com/) にアクセスします。
2. 画面上の「選択をすべて解除」をクリックしてチェックを全て外します。
3. 下へスクロールし、「YouTube と YouTube Music」の項目のみチェックを入れます。
4. 「YouTube のすべてのデータが含まれます」というボタンを押し、「履歴」のみを選択してOKを押します（動画等のデータはファイルサイズが肥大化するため不要です）。
5. 「複数のフォーマット」ボタンから、履歴の形式が「JSON」になっていることを確認します。
6. ページ下部の「次のステップ」を押します。
7. 設定は変更せず「エクスポートを作成」を押し、処理完了後に届くメール等からZIPファイルをダウンロードして解凍します。
8. 展開されたフォルダ内にある `Takeout/YouTube と YouTube Music/履歴/watch-history.json` を本ツールで使用します。

### 読み込みと操作手順

* 画面中央の枠内に取得した `watch-history.json` をドラッグ＆ドロップするか、ファイル選択ボタンから読み込ませてください。複数ファイルの同時選択も可能です。
* 画面右上のメニューから、集計期間の変更やCSV形式でのランキングデータのダウンロード、JSON形式でのバックアップ保存が行えます。
* 検索枠に文字を入力すると、リアルタイムでランキングが絞り込まれます。
* 各項目の右側に表示されるコピーボタンで、楽曲名などをクリップボードにコピーできます。

## 注意事項

* YouTube側のデータ出力仕様により、一部のアーティスト名や曲名がローマ字表記で出力される場合があります。これは元データに依存する仕様です。
* `watch-history.json` には「再生開始日時」のみが記録されており「再生時間（何分聴いたか）」は記録されていません。そのため集計はすべて「再生回数」に基づくものとなります。

## 動作環境

* PC版の最新の主要ブラウザ（Google Chrome、Microsoft Edge、Firefox、Safariなど）での動作を想定しています。
* JavaScriptが有効である必要があります。スマートフォン等の小型画面には最適化されていません。
